# Contributing to ClipForge

ClipForge is open source and contributions are welcome, but every change needs
the maintainer's approval first.

1. Open an issue describing the bug or idea and wait for @omairtemurian to
   approve it ("approved" label or a reply).
2. Only then open a pull request that links the issue. Pull requests without an
   approved issue are closed.
3. `make check` must pass. Every pull request needs @omairtemurian's review
   before it can be merged; nobody else can merge or push to `main`.

By contributing you agree your work is released under the MIT license.
