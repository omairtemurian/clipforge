# Feature parity

OpusClip-style features against what ClipForge does today (SPEC 10). The
status and notes are the normal pipeline (v1/v2); the v3 column is what the
opt-in Pro Edit adds (SPEC-v3, "—": nothing). Status: done, partial, or not
planned.
